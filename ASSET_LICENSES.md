# Asset inventory

- Portal, island, trees, rocks, arch and waterfall: original procedural geometry in this repository. No third-party model or texture.
- Portal runes, particle/edge shaders, intro and all sound effects: original code/synthesis. No film/game recordings or third-party sound files.
- App favicon: original geometric A/ring monogram in src/app/icon.svg.
- Test landmark trajectories and synthetic canvas camera backgrounds: original generated fixtures. They are not human recordings. Real-runtime tests download public MediaPipe assets; no weights or private camera footage are committed.
- Lucide icons: lucide-react, ISC license. See installed dependency license.
- Typography uses installed system sans-serif fonts. No external font requests or bundled font assets.
- Three.js: MIT.
- MediaPipe Tasks Vision: Apache-2.0 package; Hand Landmarker model downloaded from Google's official MediaPipe storage. Review upstream model distribution terms before redistributing it; this repository does not bundle model weights.
- No personal recordings, downloaded model weights or API credentials are tracked.

An overall project license has not been chosen; no open-source licensing claim is made for original project code.
